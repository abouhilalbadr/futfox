Privacy

Privacy policy

Last updated 25 October 2026

The short version: FutFox is a Chrome extension for the EA SPORTS FC 27 Ultimate Team Web App. It has no account, no server, no analytics and no ads. It does not collect, sell or share any personal data.

Where FutFox runs

FutFox only runs on the Web App's pages at www.ea.com/…/ultimate-team/web-app/. It does nothing on any other site.

What it reads

  • The SBCs and requirements the Web App has already loaded.
  • Your club list, only when you press Load my club. FutFox asks the Web App for it the same way the Club screen does, one page every few seconds. That request goes to EA, like everything else the Web App does.
  • The Gallery details EA includes in the club pages the Web App receives (each card's Gallery score, collected mark and number of owners), to fill the Gallery tab. FutFox reads these replies as they arrive and never changes them.

This information stays in the page while it's open. FutFox never sends it anywhere else.

What it stores

Your panel options (for example "Keep players rated 87 and above") are saved in your browser's local storage for the Web App, under the key futfox.settings. Nothing else is stored. Clearing your browser's site data for ea.com removes it.

What it never does

FutFox never buys, bids, lists cards, moves players, saves squads or submits SBCs. It doesn't read your EA password or payment details.

This website

This site uses no cookies, analytics or trackers, and hosts its own font. It's hosted on Vercel, which keeps standard server logs, such as IP addresses, to run and protect the service.

Changes and contact

If this policy changes, the date at the top changes with it. Questions: open an issue on GitHub.
