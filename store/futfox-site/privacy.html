Privacy

Privacy policy

Last updated 26 October 2026

The short version: FutFox is a Chrome extension for the EA SPORTS FC 27 Ultimate Team Web App. It has no account, no analytics and no ads. Apart from a once-a-day download of the public list of Gallery sets, it talks only to EA, the way the Web App does. It does not collect, sell or share any personal data.

Where FutFox runs

FutFox only runs on the Web App's pages at www.ea.com/…/ultimate-team/web-app/. It does nothing on any other site.

What it reads

  • The SBCs and requirements the Web App has already loaded.
  • Your club list, only when you press Load my club. FutFox asks the Web App for it the same way the Club screen does, one page every few seconds. That request goes to EA, like everything else the Web App does.
  • The squad builder's player list, only when you press Pick player on a Gallery slot or a grade under Suggest cards on a Gallery set (one search for each different empty slot, a moment apart). This search also goes to EA, the same way the Web App's squad builder does.

This information stays in your browser. FutFox never sends it anywhere else.

Gallery sets

The Web App doesn't share Gallery data, so FutFox publishes the list of Gallery sets itself, as a public file on Google Firebase. Once a day the extension downloads that file from firestore.googleapis.com. The request carries no cookies and nothing about you or your club. Like any website, Google sees your IP address when the file is downloaded.

What it stores

FutFox keeps these in your browser's local storage for the Web App. None of it leaves your computer:

  • futfox.settings: your panel options (for example "Keep players rated 87 and above"), the Gallery slots you marked as done in the game and the cards you picked.
  • futfox.galleryMemory.…: the Gallery cards FutFox has seen in your club (player, rating, version, club, league, nation and Item Score), one list per Ultimate Team account, so cards you've placed in a set still count.
  • futfox.gallerySets: a copy of the Gallery sets list, so it's downloaded only once a day.

Clearing your browser's site data for ea.com removes all of it. If you use Export in the panel, FutFox saves a file with your seen cards, done slots and picks to your computer; it doesn't send it anywhere.

What it never does

FutFox never buys, bids, lists cards, moves players, saves squads or submits SBCs. It doesn't read your EA password or payment details.

This website

This site uses no cookies, analytics or trackers, and hosts its own font. It's hosted on Vercel, which keeps standard server logs, such as IP addresses, to run and protect the service.

Changes and contact

If this policy changes, the date at the top changes with it. Questions: open an issue on GitHub.
