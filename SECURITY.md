# Security policy

FutFox is a read-only Chrome extension: it never buys, bids, lists, moves players, saves
squads or submits SBCs. If you find a way it could change someone's account, leak data or run
code it shouldn't, please report it privately.

## Reporting a vulnerability

Use GitHub's private reporting: open the repository's **Security** tab and choose
**Report a vulnerability**. Please don't open a public issue for security problems.

Include what you found, the steps to reproduce it and the FutFox version (from
`manifest.json`). You can expect a first reply within a week.

## Supported versions

Only the latest version on the `main` branch is supported.
